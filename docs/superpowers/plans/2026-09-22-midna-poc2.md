# Midna POC2 implementation plan

Goal: Preserve POC1's companion behavior and accepted voice mapping while making Midna readable, color-responsive, and less rigid.

Baseline: SoH integration f889527c4c0f97403eae3806e43ec367cd22c7ad. POC1 pack SHA-256 1d3ab51863432b1948c53117331fd35c27a6786c63d0ba2cc4fa4ad129dfb810. POC1 is preserved.

User-approved design: Hm replaces emergence/dash, spaced out to avoid repeated NPC targeting chatter. Primary colors drive Midna's existing turquoise markings; secondary colors drive small magical motes. Suppress the native spherical glow only when Midna renders. Animate within the existing pose, including limbs and ponytail, without changing gameplay movement. Complete all changes before the next push.

Global constraints: retain all cumulative SoH integration features; ordinary fairies unchanged; missing-pack fallback; same shared child/adult size; existing Hey, laughs and Vanish unchanged. No ComboShip port. Runtime/Alt parity cannot be claimed from offline evidence.

Implementation:

- [x] Audio: use the existing mixer timeline for a shared eight-second DASH/APPEAR cooldown. A suppressed available cue returns handled so vanilla audio does not leak through. Other events remain independent. Init clears the cooldown; scene voice teardown retains it. Test rapid alternating cues, expiry during silence, speech/recall, missing clips, and no queued playback.
- [x] Asset pack: copy POC1 resources byte-for-byte, replace only two audio entries with resampled Hm at -6 dB, and add versioned POC2 resources. Export the original topology into a 64-frame 3.2-second gentle pose loop. Reuse frame vertex arrays for both body and markings; use one matrix for the model. Generate a technical color mask from the existing turquoise markings and preserve other texture pixels. Use six small fading motes, not a filled halo.
- [x] Actor: select POC2 resources when complete, otherwise draw POC1. Bind the current pose to segment 8; draw the normal body, then a masked primary-color decal and secondary-color motes. Use native innerColor/outerColor so existing target-category transitions and cosmetic settings apply. Restore native glow when model loading fails.
- [x] Verification: run production audio/draw diagnostics before and after changes, compile the entire actor C unit, inspect resource references/vertex indices and the complete pack diff, render actual animated mesh and four target palettes, and review the final code before publishing.
- [ ] Delivery: preserve source/export scripts and evidence in a POC2 checkpoint; save the combined mod, preview, and handoff. A build success remains distinct from in-game acceptance.
- [x] Follow-up blink request: preserve the original open eye, add native-material half/closed atlases for the complete iris and sclera, use the actor update clock for an occasional 200 ms blink, and retain open-eye fallback. Generated lid artwork was rejected by the user and excluded. Inspect the actual exported states on the model before the authorized push.

Review focus: cooldown falling through to vanilla; malformed/partial POC2 packs; native/Alt resource reloads; mesh/UV seams during motion; masked tint or motes washing out the face. Gameplay tests remain crowd targeting, all four color categories, child/adult, Alt off/on, and scene reentry.

Review outcome: corrected the shimmer's fog blender so its vertex alpha remains a soft edge; require loaded shimmer vertices and both textures before selecting POC2. Regression assertions passed after observed failures. Independent recheck found no remaining concrete issue for an offline candidate. Delivery is recorded in the separate POC2 handoff once the candidate build is published.
