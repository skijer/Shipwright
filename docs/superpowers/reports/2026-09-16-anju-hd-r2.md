# HD Anju R2: umbrella grip and fitted skirt

Continuation of the approved R1 artwork on `feat/anju-umbrella-kafei`, based on
local commit `57913ab4`. This is a model review draft. No fork push, build trigger,
catalogue expansion or runtime change is part of this step.

## Model changes

- The right hand's four fingers curl around the unchanged native umbrella shaft.
  A separate continuous thumb bend closes the projecting thumb against the grip.
  Skin and nail geometry use the same deformation field. The wrist seam and all
  vertices owned by the forearm remain exact. The opposite hand is unchanged.
- The lower skirt tapers progressively below the hips, reaching 28% less width
  and 30% less depth in the common fitting space. The waist and decorative hem
  UV layout remain. The seated side silhouette retains native folds but has less
  excess volume.
- Previously concealed upper calf surfaces poked through the tighter skirt at
  the seated knees. Those surfaces are clipped inside the garment. Existing
  exposed calf vertices and both complete foot/heel graphs are retained exactly.
  This is not a rescale of her legs or a change to skeleton offsets.
- The seven texture payloads are byte-identical to R1, including the approved
  auburn hair and sheen, clothes, original blue eyes and umbrella artwork.
  All blink heads and every native umbrella resource are also unchanged.

The fitting script operates in the original hand's local space and a common
pelvis space derived from the source standing frame. Vertex normals follow the
inverse-transpose deformation Jacobian. The exporter rejects a sampled local
volume inversion. This check does not claim to prove absence of every possible
surface intersection; actual archive renders supply the visual check.

## Scope and review

The seated crying pose remains `0x7E0D`. Standing umbrella idle is rendered using
its complete native 32-frame animation as an offline candidate; it has no new
catalogue parameter in this change. The seated preview uses all 43 native frames.
Both GIFs are 20 fps and read the actual exported graph. Preview blink placement
is illustrative; the existing runtime still uses each actor's randomized timer.

The previews keep the complete umbrella and actor origin inside a fixed camera.
A separate close-up shows the actual hand, nail and shaft geometry. They are
offline renders, not in-game captures. Furniture is not included.

World/home position, Y/yaw placement anchors, native joint offsets, animations,
scene reentry ownership and runtime code are unchanged. The R2 pack still needs
the prepared Anju adapter build; it is not intended for the currently published
older build. User preview approval and a later in-game check remain outstanding.

## Reproduce

Use the same supplied archives and four approved PNGs from R1:

```sh
python3 scripts/diagnostics/build_anju_hd.py MM_ARCHIVE SOURCE_HD_ARCHIVE OUTPUT_DIR \
  --hair ART/hair_vanilla_auburn.png --clothes ART/clothes_refined.png \
  --shirt ART/shirt_refined.png --umbrella ART/umbrella_pattern_hd.png \
  --revision R2 --export-only
python3 scripts/diagnostics/render_anju_hd_fit_review.py MM_ARCHIVE \
  OUTPUT_DIR/Anju_HD_Auburn_Umbrella_R2.o2r PREVIEW_DIR
```

`--revision R1` selects the original fitting and archive name for comparison.
