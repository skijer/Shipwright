# Child Kafei implementation

Task 3 adds identity 21 with idle `0x7E0B` (89 frames) and gesture `0x7E1B`
(48 frames). Dialogue remains “I've made a promise to Anju.” Presentation defaults
are scale .01, collider 18/60/0, focus 45 and talk distance 80; neither pose tracks.

Kafei has an isolated retained resource route. Before any factory parsing it
checks the exact OANM wrapper and OPAM payload lengths, type/version, frame count,
entry count and embedded path. The existing PlayerAnimation factory parses only
the validated payload. No global Link animation wrapper factory is invoked.
The donor skeleton's misleading Standard tags are accepted only with the exact
finite Kafei signature: 21 ordered LOD children, hierarchy/positions, 18 nonnull
near/far display lists, and full byte consumption. Every child is parsed directly
from the MM archive and retained behind a private header. No cached/global skeleton
or child is modified. All 12 face textures have typed retained ownership.

The viewer uses InitFlex with a null animation and checks the 22 joint/morph
allocations and 18 matrix slots. An independent native-rate full-loop cursor
copies exactly 66 joint words and handles appearance separately. Negative,
fractional and multiple-loop steps are bounded; nonfinite steps leave state
unchanged. The draw callback applies MM's 11/17 adjustment to local root position
only, then DrawFlexLod uses near LOD. No Link init/update, animation queue, player
hooks, attachment, quest, or audio route is used. Failure and repeated teardown
release tables before their retained resources; uninitialized draw/update do nothing.
