# HD Anju R3: vest, shoe fronts, and standing hand candidate

R3 responds to the user's front-view shoe defects and vest clipping. The user
preferred a relaxed left hand contrasting with the umbrella grip. The relaxed
hand is a separate standing preview resource; the seated crying gesture stays
exact. No fork push is authorized at this review stage.

## Diagnosis and correction

The R1/R2 heel fitting raised only sole vertices below a cutoff, allowing the
raised sole to pass through higher shoe surfaces. R3 applies a continuous
vertical compression across the whole arch section, preserving the narrowed
heel and rear upper shape. The source shoe UVs, triangle topology, bone owners,
and ankle/shin seam rows remain unchanged. Normals use the deformation's
inverse-transpose Jacobian instead of recomputing mixed-bone face normals.

The vest and lowest button were split between torso, pelvis, and skirt-root
bones. Different native umbrella rotations pulled the lowest button into a
spike and disrupted the hem. R3 rebinds the full button to the torso, puts the
full belt ring on the pelvis, and tucks the lowest vest ring into that belt.
The visible upper vest follows the torso while its tucked ring follows the
pelvis. Duplicate UV-seam vertices receive the same correction.

Only nine existing source batches change: 3, 4, 5, 19, 20, 27, 34, 35, and 36.
Both original hands, head/blink resources, umbrella, and all seven textures
remain byte-identical to R2. The rest of the R2 fitted skirt and calf treatment
are retained.

## Relaxed standing hand

The additional root is
`objects/object_anju_hd/v1/gAnju1RelaxedLeftHandDL`, with separate skin and nail
display lists and vertex arrays (five added resources in total). It softly curls
four fingers, leaving the palm, wrist, and open thumb intact. Skin and nails
use the same deformation. The standing preview selects this root explicitly.
The existing seated adapter continues using the unchanged original left hand.

Standing umbrella idle is still a candidate without a catalogue parameter.
The seated parameter remains `0x7E0D`; the O2R requires the pending Anju HD v1
adapter build. No runtime, native skeleton/animation, placement Y/yaw, collision,
or reentry code changes are part of R3.

## Verification

- Actual production archive fixture: 19 limbs, three blink heads, umbrella,
  2,941 owned vertex loads, complete fallback, and eight Alt/cache-reentry cycles.
- ZIP CRC/private namespace checks: 134 resources, five candidate additions.
- All seven texture payloads, both original hands, three head states, and
  umbrella graph are byte-identical to R2.
- 74 and 78 ankle/shin seam rows are exact. Each shoe retains 24 recorded heel
  and toe contact vertex positions from R2.
- Minimum sampled shoe Jacobian determinant: 0.18854, positive on both feet.
- Across all 32 standing and 43 seated frames, the lowest sole height differs
  from R2 by at most 0.598 model units standing (under one integer coordinate
  unit, about 0.006 world units) and exactly zero seated. The tiny standing
  difference comes from quantizing the smoother forefoot transition; actor
  placement and ankle positions are unchanged.
- Explicit `--revision R2` rebuild reproduces all 129 prior resource payloads
  byte for byte. The R1 path is retained unchanged.
- Python compilation and `git diff --check` pass. Runtime source is unchanged;
  the R2 report records its existing 15-test CTest gate.
- Independent code/archive/close-up review found no blockers. Native-motion
  offline previews cover the complete 32/43-frame loops at 50 ms per frame.
  This does not constitute an in-game Windows test.

## Reproduction

Use the same native/source archives and four approved PNGs documented in R1:

```sh
python3 scripts/diagnostics/build_anju_hd.py NATIVE_MM SOURCE_HD OUTPUT_DIR \
  --hair hair_vanilla_auburn.png --clothes clothes_refined.png \
  --shirt shirt_refined.png --umbrella umbrella_pattern_hd.png \
  --revision R3 --export-only
python3 scripts/diagnostics/render_anju_hd_fit_review.py NATIVE_MM \
  OUTPUT_DIR/Anju_HD_Auburn_Umbrella_R3.o2r PREVIEW_DIR
```

The renderer reads the revision metadata for filenames and labels, and can
produce just the two new detail sheets with `--details-only`.
