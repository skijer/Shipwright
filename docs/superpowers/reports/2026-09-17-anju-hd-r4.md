# HD Anju R4 review draft

The R3 umbrella hook intersected the palm and its shared grip required an abrupt wrist turn. The left elbow also contained overlapping skin triangles; the left ankle looked too thick above the shoe. This revision addresses that geometry while retaining the approved R3 artwork and body fitting. No runtime code changes or push.

## Changes

- Add `anju_hd_finish.py`: separate seated/standing palm frames derived from native forearm direction and umbrella axis; continuous thumb/finger/nail deformation; a fitted accessory translation and 280-unit straight-handle extension below the palm.
- Replace the local left elbow transition with a joined patch. Keep 26 boundary positions and 28 complete corner rows, including the original wrapped UV seam. Intermediate seam copies share normals. Retain the two existing bone owners.
- Taper the left ankle up to 16% in X/Z. Local Y, the attachment ring, toe front, heel, sole contacts and upper calf remain unchanged.
- Export standing arm and umbrella candidates separately; default roots remain seated. The seated adapter contract, blink heads, native skeleton/animation, fixed anchor and resource-lifetime protections remain unchanged. Standing still has no catalogue parameter.
- Render actual exported geometry, with close-ups and both native loops. Add an independent readback geometry diagnostic.

## Verification

- All 32 standing and 43 seated frames: finite archive readback; zero detected shaft penetrations (1 model-unit interior tolerance) and zero strict nonadjacent elbow triangle crossings. The crossing check excludes shared edges and coplanar contact.
- Wide hook stays at least 54.50 model units below the hand along the shaft axis in standing, and 54.78 seated.
- Independent review: 391 elbow-patch vertices / 730 triangles in each pose; preserved boundary attributes; shared seam normals; no zero-area faces, nonmanifold edges or reversed normal/winding faces.
- All seven texture payloads unchanged. Only expected existing geometry/metadata payloads differ. Source toe/heel contacts, ankle attachment and local Y are exact.
- R3 converter compatibility: all 134 resource payloads reproduced exactly.
- Native production graph fixture: PASS, 19 limbs / 3 blink heads / umbrella / 2994 owned vertex loads / complete fallback / 8 Alt/cache-reentry cycles.
- Python compilation, diagnostic CLI startup and `git diff --check` pass. Offline preview; no new in-game result claimed.

## Reproduce

Use `build_anju_hd.py` with the native MM archive, supplied HD Anju archive, the four approved hair/clothes/shirt/umbrella PNGs, `--revision R4 --export-only`. Earlier revisions remain explicitly selectable. Run `render_anju_hd_fit_review.py` against the produced archive. `verify_anju_hd_finish.py` takes the native archive, R3 archive, R4 archive, an R3 reproduction archive, and a JSON output path.
