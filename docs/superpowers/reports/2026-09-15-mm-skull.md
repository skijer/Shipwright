# Skull Kid texture and Tatl integration

The strict display-list patcher now installs stable filepath aliases instead of raw pixel pointers. A retained texture store snapshots the complete type, flags, dimensions, byte/pixel scales, canonical resource metadata and owned pixel buffer. Only the MM object_stk texture namespace accepts exact base/Alt replacements; the validated private donor remains mandatory fallback. Private nested display lists, vertices, culls, cycle bounds and graph ownership remain unchanged. The cache republishes evicted or dirty aliases before Skull Kid draws, without promising live resource-pack reload.

Tatl uses the actual seven-argument native skeleton callback at body limb 8. It preserves the transformed origin, resets inherited rotation/scale and applies the native body pulse plus existing presentation scale. Wings, companion anchor, billboard display list and stable segment-08 setup remain unchanged. Phantom Ganon's model-only 1000 offset at scale .01 remains intact.

## Verification

Commands from repository root:

```sh
source .superpowers/sdd/mm-recovery/build-env.sh
python3 docs/superpowers/reports/appendices/mm_texture_verify.py ../build-mm-catalogue ../donor-inputs/mm.o2r --compile-production
bash scripts/diagnostics/run_stabilization_tests.sh ../donor-inputs/mm.o2r
```

Passed the actual texture factory on all 30 Skull Kid donor textures; real ResourceManager and Fast filepath interpreter checks for metadata, base/Alt/base toggles, stable paths, namespace restriction, invalid replacements, deep-copy isolation, dirty/evicted aliases and independent bindings. The fixture explicitly skips the archive's zero-byte non-texture gSkullKidSkelLimbs marker. Malformed texture extents, image representation, flags and nonfinite scales are rejected.

The real Tatl callback runs with verbatim production matrix functions: three phases and three actor scales preserve origin, remove inherited rotation, retain display-list/position/rotation arguments and leave other limbs untouched. Math_SinS is a sine boundary fixture; graphical rendering and interpolation replay are not simulated.

Actual archived graph rewriting passes for 22 display lists, 59 texture commands and 34 culls. The complete existing stabilization suite passes, including actor catalogue, Phantom anchoring, audio, weather and night-combat behavior. All three changed production translation units compile with normal game flags into temporary objects. Independent strict-module and combined integration reviews report no serious blockers. No shared Ninja process was used for these checks.

These are CPU/resource/command checks. Skull Kid's original missing-pixel symptom is not declared visually resolved: stock and Alt-pack appearance, both poses, multiple instances and scene re-entry still need observation in the normal Windows candidate. The headless resource fixture explicitly exits after lifecycle assertions because application Context teardown assumes a Window; it does not test whole-application shutdown.
